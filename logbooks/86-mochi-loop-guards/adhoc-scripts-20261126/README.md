# Ad-hoc loop-guards scripts (snapshot, 2026-11-26)

This is a verbatim copy of the helper scripts the loop-guards workers ran out of `/tmp/mochi-loop-guards/` during S0–S2. They are preserved here so that every job submitted from them stays reproducible. They are not maintained code.

The maintained experiment code lives on the marin branch `benfeuer/mochi-loop-guards`, under `experiments/post_training/mochi_loop_guards/`. Consolidating these scripts into that package, and into the shared Iris and watchdog tooling, is tracked in the lane's STATUS.md.
