RUBRIC: Gene Module Coherence Analysis

Total Points: 100/100

Notes: This rubric evaluates whether the analysis correctly assesses internal correlation structure and coherence of myeloid detrimental and lymphoid protective gene sets. Excellence requires proper definition or derivation of gene sets (e.g., top 50 genes correlated with myeloid/lymphoid scores), computation of pairwise Spearman correlations within each gene set excluding self-correlations, reporting mean within-set correlations showing myeloid genes have moderate coherence (mean r ≈ 0.36) while lymphoid genes have strong coherence (mean r ≈ 0.64), identifying low-coherence genes using stated threshold (e.g., mean r < 0.2 identifying ~7 myeloid genes and 0 lymphoid genes), and interpreting results as indicating lymphoid genes form tight expression module while myeloid genes encompass multiple partially independent processes.

CRITERIA (7):

Criterion 1: Analysis Goal and Gene-Set Context

    Description: Assesses clear statement of research question and biological framing.
    Levels: A=10 B=5 C=0
      [A]: Clearly states that the goal is to assess within-set correlation structure and expression coherence of myeloid detrimental and lymphoid protective gene sets, explicitly frames this as evaluating whether each gene set represents a tightly co-expressed module (genes regulated together) or a heterogeneous collection of partially independent genes, contextualizes analysis within broader question of whether functional gene signatures have coherent biological basis or are just collections of individually correlated genes, and identifies the specific gene sets being evaluated (myeloid detrimental genes associated with adverse immune responses, lymphoid protective genes associated with adaptive immunity).

      [B]: Mentions correlation analysis with issues such as does not clearly connect correlation to concept of module coherence (states goal is computing correlations without explaining why this matters), biological context is vague or missing (does not explain what myeloid detrimental or lymphoid protective genes represent), unclear statement of what coherence means or why it is important to assess, or lacks specific identification of which gene sets are being analyzed.

      [C]: Analysis goal is missing entirely, incorrectly states the question (e.g., frames as correlation between myeloid and lymphoid gene sets rather than within each set), completely omits biological context making it unclear what the analysis is testing, or fundamentally misunderstands the research question (confuses within-set coherence with between-set correlation).

Criterion 2: Gene Set Definition and Extraction

    Description: Evaluates correct definition and derivation of myeloid and lymphoid gene sets.
    Levels: A=20 B=10 C=0
      [A]: Explicitly states whether gene sets are predefined from literature or data-derived from current analysis, if data-derived clearly describes derivation procedure (e.g., ranks all 104 genes by Spearman correlation with myeloid_score and selects top 50 positively correlated genes as myeloid detrimental set; ranks genes by correlation with lymphoid_score and selects top 50 negatively correlated genes as lymphoid protective set), documents correlation threshold or ranking cutoff used for gene selection (e.g., top 50 genes from ranked list), correctly extracts gene expression values for selected genes across all patients from subspace_genes.csv, verifies gene sets contain expected number of genes (e.g., 50 genes per set or documents actual count if different), lists gene names or clearly references listing in notebook output so gene set membership can be verified, and acknowledges that data-derived gene sets may bias coherence analysis (genes selected based on correlation with summary scores may artificially inflate within-set correlation).

      [B]: Uses gene sets with issues such as gene sets are used but definition or derivation procedure is unclear (does not explain whether predefined or data-derived), if data-derived the selection method is vague or incompletely documented (mentions correlation ranking but does not specify cutoff, directionality, or number of genes selected), does not verify gene set sizes or composition, gene names not reported making it impossible to verify which genes are in each set, does not extract expression values correctly (uses wrong columns or only subset of patients), or fails to acknowledge potential bias from data-driven gene selection.

      [C]: Gene set definition is incorrect or missing (does not identify which genes belong to myeloid vs lymphoid sets), uses completely wrong genes (random selection or genes unrelated to myeloid/lymphoid biology), gene expression extraction is fundamentally flawed (wrong data source, uses scores instead of expression values, or extracts non-gene variables), or gene sets are so poorly defined that subsequent correlation analysis cannot meaningfully assess coherence.

Criterion 3: Pairwise Correlation Computation

    Description: Assesses correct computation of within-set gene-gene correlations.
    Levels: A=20 B=10 C=0
      [A]: Computes pairwise Spearman correlation matrix for myeloid detrimental gene set showing correlation between each pair of genes based on expression patterns across all patients (correlating gene expression profiles not patient profiles), computes separate pairwise Spearman correlation matrix for lymphoid protective gene set using same methodology, uses Spearman correlation appropriately for gene expression data (robust to non-normality and outliers), correctly excludes self-correlations when computing summary statistics (diagonal of correlation matrix equals 1.0 but should not be included in mean within-set correlation), correlation matrices are symmetric with dimensions equal to number of genes in each set (e.g., 50×50 if 50 genes per set), verifies correlation computation is correct by checking that values fall in [-1, 1] range and diagonal equals 1.0, and clearly documents that correlations are computed within each gene set (myeloid genes correlated with each other, lymphoid genes correlated with each other) not between gene sets.

      [B]: Computes correlations with issues such as correlation methodology is unclear (does not explicitly state Spearman method or justify choice), unclear whether self-correlations are properly excluded from summary statistics (could inflate mean correlation), correlation matrices partially computed but not for both gene sets or computed incorrectly (asymmetric, wrong dimensions, or values outside valid range), does not verify correlation computation correctness, confuses within-set vs between-set correlations (some analysis mixes myeloid and lymphoid genes), or correlation analysis is present but implementation details are vague making it difficult to verify correctness.

      [C]: Pairwise correlation computation is missing entirely, uses completely incorrect correlation method (correlates patients instead of genes, or computes covariance instead of correlation), correlation matrices are fundamentally wrong (wrong dimensions, all values identical, or values outside [-1,1] range suggesting calculation error), computes between-set correlations instead of within-set correlations defeating the purpose of coherence analysis, or correlation analysis is so flawed that results cannot meaningfully assess within-set coherence.

Criterion 4: Summary Statistics of Module Coherence

    Description: Evaluates accurate reporting of mean within-set correlations.
    Levels: A=15 B=8 C=0
      [A]: Correctly computes mean within-set correlation for myeloid detrimental gene set by averaging all pairwise correlations excluding diagonal self-correlations (expected mean r ≈ 0.36), correctly computes mean within-set correlation for lymphoid protective gene set using same methodology (expected mean r ≈ 0.64), reports both mean correlation values numerically with appropriate precision (2-3 decimal places or significant figures), clearly labels which mean corresponds to which gene set (myeloid vs lymphoid), explicitly notes that lymphoid genes show higher mean correlation than myeloid genes (≈0.64 vs ≈0.36 indicating stronger coherence), may additionally report standard deviation or range of correlations within each set to characterize heterogeneity, and interprets mean correlations correctly recognizing that higher values indicate tighter co-expression and greater module coherence.

      [B]: Reports summary statistics with issues such as computes mean correlations but values substantially different from expected (>20% discrepancy suggesting calculation errors like including self-correlations or using wrong subset of genes), reports mean for only one gene set (myeloid or lymphoid but not both), unclear labeling making it difficult to determine which value corresponds to which gene set, does not explicitly compare myeloid vs lymphoid mean correlations (reports both but does not note which is higher), insufficient precision (excessive rounding losing information), or summary statistics are partially reported making verification difficult.

      [C]: Mean within-set correlations are not computed or reported, reported values are completely incorrect or fabricated (inconsistent with computed correlation matrices or impossible given data), reports between-set correlation instead of within-set means (e.g., reports correlation between myeloid and lymphoid sets rather than mean within each set), or summary statistics are so wrong that they cannot inform assessment of module coherence.

Criterion 5: Identification of Low-Coherence Genes

    Description: Assesses identification of genes poorly correlated with others in their set.
    Levels: A=15 B=8 C=0
      [A]: Identifies genes with low mean correlation to other genes in the same set using stated criterion or threshold (e.g., defines low-coherence as mean correlation < 0.2 or uses other justified cutoff), computes mean correlation for each gene by averaging its correlations with all other genes in the set (excluding self-correlation), identifies approximately 7 myeloid detrimental genes with mean correlation below threshold (e.g., AZU1, KIF15, HMMR, CEP55, BPGM, IL1A, EPB42 with mean r < 0.2), identifies zero or very few lymphoid protective genes below threshold indicating all lymphoid genes are well-correlated with others in the set, clearly lists identified low-coherence genes or references their listing in notebook output, acknowledges that threshold for "low coherence" is heuristic or data-driven (not absolute biological cutoff), and interprets presence of low-coherence genes in myeloid set but not lymphoid set as evidence of differential module coherence.

      [B]: Identifies low-coherence genes with issues such as mentions low-coherence genes but does not state clear criterion or threshold used for identification (unclear how genes were selected), identifies genes for only one set (myeloid or lymphoid but not both), gene list is incomplete or unclear (mentions some low-coherence genes but does not provide complete list or reference), threshold appears arbitrary without justification or acknowledgment of heuristic nature, does not compute mean correlation per gene systematically (uses ad-hoc approach or visual inspection), or identification is present but methodology is vague making it difficult to verify which genes qualify as low-coherence.

      [C]: Does not identify or attempt to identify low-coherence genes in either set, identification is completely incorrect (lists genes that actually have high mean correlation, or fabricates gene names not in the gene sets), uses fundamentally wrong methodology (e.g., identifies genes based on variance instead of correlation), or low-coherence analysis is missing entirely preventing assessment of within-set heterogeneity.

Criterion 6: Interpretation and Limitations

    Description: Assesses biological interpretation of coherence differences and acknowledgment of limitations.
    Levels: A=20 B=10 C=0
      [A]: Correctly interprets higher mean correlation among lymphoid protective genes (r≈0.64) compared to myeloid detrimental genes (r≈0.36) as indicating lymphoid genes form tighter and more coherent expression module, explains biological interpretation that lymphoid protective genes likely reflect shared underlying regulatory program or coordinated adaptive immune response (genes turn on and off together), interprets lower correlation among myeloid genes as suggesting this set encompasses multiple partially independent myeloid-associated processes rather than single tightly regulated module (heterogeneous collection of inflammatory pathways), notes that presence of low-coherence myeloid genes (mean r<0.2) but absence of such genes in lymphoid set further supports differential module coherence, relates findings to biological modularity concept (tightly co-regulated gene sets represent functional modules, loosely correlated sets represent diverse processes grouped by association with phenotype), acknowledges key limitations including that data-derived gene sets may bias coherence (selecting genes by correlation with myeloid/lymphoid scores could artificially create or enhance within-set correlation structure), threshold for low coherence is heuristic and results could change with different cutoff, and gene set definitions affect results (top 50 genes is arbitrary choice, different set sizes might yield different coherence patterns).

      [B]: Provides interpretation with issues such as correctly identifies differential coherence (lymphoid > myeloid) but does not clearly explain biological meaning or implications for module structure, biological interpretation is vague or superficial (states genes are "correlated" without discussing coordinated regulation or shared programs), does not fully explain why differential coherence matters for understanding immune gene organization, mentions limitations superficially without specific details (states "analysis has limitations" but does not identify gene-selection bias, threshold arbitrariness, or set size choices), or interpretation is incomplete missing important connections between statistical findings and biological modularity concepts.

      [C]: Misinterprets coherence results (claims myeloid genes are more coherent than lymphoid genes contradicting data, or states no difference when clear difference exists), provides biologically incoherent interpretation (explanations contradict known immune biology or gene regulation principles), overclaims by treating data-derived patterns as definitive biological truth without acknowledging potential biases from gene selection methodology, fails to acknowledge any limitations presenting findings as if they are objective properties of gene sets rather than analysis-dependent results, or provides interpretation completely disconnected from the correlation analysis results.
