Criterion 2: Per-Donor Percentage Calculation

    Description: Evaluates correct calculation of cell type percentages at the donor level rather than global percentages.
    Levels: A=15 B=7 C=0

      [C]: No percentage calculation or fundamentally wrong approach (e.g., uses raw cell counts without accounting for different total cells per donor).

Criterion 4: Statistical Analysis

    Description: Evaluates use of appropriate statistical test and multiple testing correction.
    Levels: A=20 B=10 C=0
      [A]: Uses appropriate statistical test (WLS with cell counts as weights preferred to account for different precision across donors, or Wilcoxon/Mann-Whitney rank-sum test as a robust non-parametric alternative) with proper multiple testing correction (e.g., Benjamini-Hochberg FDR correction, Bonferroni) and reasonable significance threshold (e.g., FDR < 0.05 or adjusted p-value < 0.05). Clearly reports test statistics and both raw and corrected p-values.

      [B]: Appropriate test but no multiple testing correction (uses raw p-values risking false positives when testing 11 cell types), OR correction applied but inappropriate test (e.g., parametric t-test without checking normality assumptions).

      [C]: No statistical testing or fundamentally flawed approach (e.g., no group comparison, treats cells as independent units instead of aggregating by donor, or uses inappropriate test like chi-square on continuous percentages).
