# Lossless AgentX server-metrics capture

`large-server-metrics.patch` is a separate owner integration patch, based on Marin `ce69fe2538f26525a75d8d96e1820dce68cc568d`. It applies cleanly to the owner branch at `cab4b9112a4df1e52b73271ff5649e3411d19839` (`git apply --check`, 2026-10-29). The owner branch and its worktree were not edited. The AgentX runner is not yet on Marin main, so this is not a standalone main-branch PR.

A completed sixteen-GPU router run lost its leader archive because its raw server-metrics export exceeded the native 2 GiB regular-file capture limit. This patch packs that JSON losslessly after measurement and cleanup, verifies decoded SHA-256 before deleting the original, and restores and verifies it before the unchanged upstream processor runs. It keeps support for existing plain JSON. No benchmark duration, workload, model arithmetic, dependency, or shared Iris capture policy changes.

Validation: all 23 focused AgentX tests pass, including a real native archive capture that rejects the raw fixture and accepts its packed form, and byte-exact restoration. Scope checks pass for all five changed files. Native Codex 6.1 sol xhigh advisory review found no material issues. The broader required affected CPU suite selected 253 files and ended at its native 600-second limit: 2,920 passed, 31 failed, 6 skipped, 5 xfailed. Three representative failures in Harbor, Docker image worktrees, and local Lean sandbox reproduce on the unmodified base. This broad check is not reported as green; unrelated infrastructure was left unchanged.

Independent live-size experiment: the 32-GPU export is 4.7 GB. Lossless packing, decoded hash verification, native 2 GiB archive acceptance, permanent upload, and readback all passed. The research wrapper already uses this post-measurement packing, without applying the owner patch. The router wrapper also collected duplicate physical metrics through backend and router URLs; the future wrapper now uses one deduplicated URL. Even one 32-GPU stream exceeds 2 GiB, so packing remains needed.
