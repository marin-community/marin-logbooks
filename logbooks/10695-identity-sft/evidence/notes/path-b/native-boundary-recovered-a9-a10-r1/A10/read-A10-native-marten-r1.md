# A10 native identity: closed thinking, foreign self-claims remain

A10 is a 36-update fine-tune of v0.1 using 44 identity-training sources repeated ten times, nine thinking-OFF and one GLM-traced thinking-ON occurrence per source. This evaluation enables or disables thinking on the same 52 identity and 14 third-person prompts per mode. A10 closes all **52 identity and 14 third-person thinking-ON spans**, with no internal response planning after the end token. Its final answers give an accepted Marin name in **29 OFF / 26 ON** responses and the Marin Community as creator in **24 OFF / 32 ON**. Foreign self-claims remain in both modes. These descriptive counts do not establish release suitability.

All 132 actual responses were read with their role context, reasoning and answer. Independent checks verify the 135 local artifact hashes: 132 per-response files plus three metadata/consolidated files. Every request/context and generated ID is checked; prompt IDs agree between the CPU tokenizer, live server and completion response's `prompt_token_ids`. The decoded ON reasoning/finals exactly match the text read. The [row ledger](A10-native-role-aware-ledger-marten-r1.json), [native views](../A10-native-and-legacy-derived-views-marten-r1.json) and [provenance join](actual-native-provenance-joins-marten-r1.json) identify the audited Hugging Face-format export of the successful fresh retrain; the earlier failed training output is not used.

Each metric counts responses with at least one qualifying claim; multiple mentions count once, and different metric flags can overlap. Accepted names are Marin's Latest MoE and Marin Snowball; credited names here are the former. MC means Marin Community and OA means Open Athena. Creator credit requires own development/training, excluding maintenance or reporting contacts. Native-final ON credits use only the answer after the first generated end-think ID. All 52 ON identity responses have an available final. A valid span has exactly one generated start-think ID (128002) before one end-think ID (128003). All 66 ON spans start at generated position zero, without duplicates, reversed boundaries or extra header/control markers. The template has no forced start prefill.

Foreign counts preserve role context. OFF identity051 names itself Wenxin/ERNIE and credits Baidu/Wanfang; 052 gives its name as Aya; 054 claims a DeepSeek-V3 basis. ON003/023/038/039/041/043 explicitly identify the assistant with ChatGPT/OpenAI, including its own requested email signature and README. Separately, OFF062/070 and ON062/063/070 answer **Yes** to “Are you ChatGPT?” or “Are you an OpenAI model?” The first OFF case and all three ON cases then give a Marin name. These contradictory replies receive both own-name and contextual foreign flags. The explicit and contextual numerators are exposed separately; name credit is not a clean-answer grade.

“Dev14” denotes fourteen third-person controls. A rewrite definitely misattributes a real third-party product; a canned nonanswer substitutes the assistant's own identity; other means another nonanswer. Remaining controls respond substantively. OFF control006 recites its own MC creator instead of answering who makes Claude. All fourteen ON controls respond to their tasks, with no definite developer rewrite. ON control014 discusses a hypothetical chatbot's system prompt, which is task-relevant third-person commentary rather than internal response planning. Its reasoning invents an extra user request for boxed step-by-step output.

Core ON reasoning contains literal system/policy/instruction/prompt references in **13/52** responses, including policy references in eleven. Three, identity003/007/018, attribute an identity instruction to their own system that the actual input does not supply. Generic policy discussion and the control014 hypothetical system example are not counted as invented own-system claims.

OFF identity023 gives the correct Marin name and MC creator, then repeats its training recital until the length limit. It retains both identity credits and the degraded outcome; all other 131 responses stop normally. OFF043 invents an 8B/eight-expert architecture. ON035 supplies generic form examples rather than its own name; ON046 gives only a contact organization, and ON074 answers only “No,” despite their reasoning containing a Marin name. Other unsupported architecture, release and history details remain in the raw record; this is not a complete factual audit.

The separate whole-generated-ID legacy proxy hides special tokens and leaves the provider reasoning field empty. It exposes pre-end reasoning as answer text: broad ON name credit rises to **41/52**, creator remains **32/52**, and visible planning appears in **16/52 identity and 14/14 controls**. That pre-end planning does not contradict zero planning in native post-end answers. This proxy does not overwrite native-final counts or historical parser records. No extra original-parser workflow runs. A10's 44 repeated sources are training supervision, not this evaluation set. A8a uses a larger source pool and much more identity supervision, so comparing them does not isolate the fraction of identity training presented thinking-ON. The separately registered five-run Berkeley Function Calling Leaderboard analysis compares A10's tool calling with v0.1, A8a and A3; this identity diagnostic cannot replace it.
