Here “native” means the answer is split using returned generated token IDs, with only text after that token credited as the ON final. Those finals name Marin's Latest MoE in 32/52 cases and correctly attribute development/training to the Marin Community in 40/52. One final instead signs itself ChatGPT. Format closure therefore does not imply correct identity or factual content.

Foreign self-claims affirm a different model identity or creator; quoted descriptions of other models are excluded.
